# Mensagem do Dia

Uma aplicação simples em Express e EJS que busca uma citação de Ron Swanson na
[API Ron Swanson Quotes](https://ron-swanson-quotes.herokuapp.com/v2/quotes) e a
exibe em uma página estilizada com Bootstrap.

## Requisitos

- Node.js 18 ou superior
- npm

## Como executar

```bash
npm install
npm start
```

Abra [http://localhost:3000](http://localhost:3000). Para escolher outra porta,
defina a variável de ambiente `PORT`.

Em desenvolvimento, use `npm run dev` para reiniciar o servidor automaticamente
quando os arquivos mudarem.
